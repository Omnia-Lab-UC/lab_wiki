# Omnia Lab Wiki

Quarto site for the Omnia Lab (UC) wiki: onboarding, protocols, computing, and data practices.

## Local development

```bash
quarto preview   # live-reload dev server
quarto render    # build the site into _site/
```

## Contributing

Add a `.qmd` file to the appropriate section folder — the sidebar and section
listings pick it up automatically. See [contributing.qmd](contributing.qmd)
(or the "Contributing to the Wiki" page on the site) for conventions, and
[AGENTS.md](AGENTS.md) for the ground rules that also apply to AI agents
working in this repo.
